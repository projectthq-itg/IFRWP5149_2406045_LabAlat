# Laporan Singkat Pertemuan 1

## 1. Kakas yang Digunakan
Draw.io (diagrams.net). Digunakan karena mendukung penyimpanan sumber diagram (.drawio) yang dapat dibuka dan disunting kembali, serta menyediakan fitur ekspor gambar (PNG).

## 2. Bukti Uji Buka Ulang
Setelah menyimpan file sumber `P01_2406045_latihan_activity_v01.drawio`, saya menutup tab browser dan membuka kembali file tersebut dari folder lokal. File berhasil terbuka, saya menggeser posisi salah satu elemen, menyimpannya kembali, dan mengekspornya ulang menjadi `.png`. Hal ini membuktikan file sumber tidak terkunci dan masih dapat diedit.

## 3. Kendala dan Solusi
- **Kendala**: Awalnya garis penghubung (konektor) hanya terlihat berdekatan dengan elemen, tetapi tidak benar-benar menempel.
- **Solusi**: Saya memastikan garis ditarik dari titik jangkar (anchor point) di tepi elemen, bukan hanya dari area di dekat elemen. Setelah semua garis menempel sempurna, diagram disimpan dan diekspor ulang.
