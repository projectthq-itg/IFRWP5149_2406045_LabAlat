# Logbook Praktikum Pertemuan 1

- **Kakas yang dipakai**: Draw.io (Web/Desktop)
- **Pekerjaan yang selesai**: 
  1. Membuat workspace dan struktur folder proyek.
  2. Membuat diagram aktivitas sederhana untuk S-ORI-01 (4 elemen, 3 penghubung).
  3. Menyimpan berkas sumber (.drawio) dan hasil ekspor (.png).
- **Pemeriksaan yang dilakukan**: 
  - Menutup file .drawio, lalu membukanya kembali untuk memastikan file bisa disunting.
  - Mengecek kesesuaian nama file dan versi antara sumber dan ekspor.
- **Kendala**: 
  - Sempat bingung mencari bentuk "node awal" (lingkaran hitam) di pustaka bentuk draw.io.
- **Tindak lanjut**: 
  - Mencari di menu pencarian shape draw.io dengan kata kunci "start" atau "initial", akhirnya ketemu dan berhasil diletakkan.
