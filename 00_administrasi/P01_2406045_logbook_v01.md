# Logbook Praktikum Pertemuan 1

- **Kakas yang dipakai**: Draw.io (Web & Desktop)
- **Pekerjaan yang selesai**: 
  1. Membuat workspace dan struktur folder proyek sesuai SOP.
  2. Membuat diagram aktivitas sederhana untuk S-ORI-01 (4 elemen, 3 penghubung).
  3. Menyimpan berkas sumber (.drawio) dan hasil ekspor (.png).
- **Pemeriksaan yang dilakukan**: 
  - Menutup file .drawio, lalu membukanya kembali untuk memastikan file dapat disunting (tidak corrupt).
  - Mengecek kesesuaian nama file dan versi antara sumber (.drawio) dan ekspor (.png).
- **Kendala**: 
  - Kesulitan menemukan konektor yang menempel sempurna pada elemen saat menggunakan draw.io versi web.
- **Tindak lanjut**: 
  - Mengarahkan kursor tepat ke titik (dot) di pinggir elemen sebelum menarik garis, sehingga garis terkunci dan menempel pada elemen. Ekspor ulang gambar dilakukan setelah perbaikan.
